KNN Regression Data (NO₂ Kabupaten Bangkalan)

K-Nearest Neighbors (KNN) Regression merupakan metode machine learning yang melakukan prediksi berdasarkan kemiripan antara data baru dengan data historis yang sudah ada. Pada proses prediksi, algoritma mencari K titik data terdekat (tetangga terdekat) di data latih, kemudian menghitung rata-rata nilai target dari tetangga tersebut untuk dijadikan hasil prediksi.

Dalam konteks kasus prediksi kadar NO₂ di Kabupaten Bangkalan, nilai lag (misalnya NO₂ satu hingga lima hari sebelumnya) digunakan sebagai fitur yang mewakili kondisi historis. KNN akan mencari periode masa lalu yang memiliki pola lag serupa, lalu memperkirakan kadar NO₂ hari berikutnya berdasarkan rata-rata kadar NO₂ pada periode-periode yang mirip tersebut.

Mengapa Nilai R-Squared Rendah pada Eksperimen?

Hasil eksperimen menunjukkan bahwa nilai R-Squared (R²) relatif rendah, berkisar antara 0.076 hingga 0.403, dengan model terbaik terdapat pada lag 2 hari (R² = 0.403). Nilai R² yang rendah menandakan bahwa variasi kadar NO₂ hari ini tidak dapat dijelaskan dengan baik hanya oleh data NO₂ beberapa hari sebelumnya.

Fenomena ini wajar, karena Variabel lingkungan lain tidak disertakan dalam model—seperti suhu, kecepatan angin, curah hujan, dan aktivitas kendaraan—yang secara nyata memengaruhi penyebaran dan konsentrasi NO₂. Dengan demikian, KNN hanya “menebak” dari pola serupa di masa lalu menggunakan informasi yang sangat terbatas.

def predict_next_day(model, scaler, feature_values):
    """
    Prediksi nilai NO2 hari berikutnya dengan input yang benar
    """
    import numpy as np
    
    # Reshape input untuk prediksi
    input_data = np.array(feature_values).reshape(1, -1)
    
    # Normalisasi input
    input_scaled = scaler.transform(input_data)
    
    # Prediksi
    prediction = model.predict(input_scaled)[0]
    
    return prediction

def predict_all_models():
    """
    Prediksi menggunakan semua model lag - VERSI YANG DIPERBAIKI
    """
    
    models_data = [
        (day1, 1, "LAG 1 HARI"),
        (day2, 2, "LAG 2 HARI"),
        (day3, 3, "LAG 3 HARI"), 
        (day4, 4, "LAG 4 HARI"),
        (day5, 5, "LAG 5 HARI")
    ]
    
    predictions = {}
    
    for data, lag, name in models_data:
        print(f"\n=== {name} ===")
        print(f"Dataset shape: {data.shape}")
        print(f"Columns: {data.columns.tolist()}")

        # Prepare data
        X = data.drop(columns=['NO2'])  
        y = data['NO2']                
        
        print(f"Features: {X.columns.tolist()}")
        
        scaler = StandardScaler()
        X_scaled = scaler.fit_transform(X)
        
        knn = KNeighborsRegressor(n_neighbors=12)
        knn.fit(X_scaled, y)
        
        # Ambil feature values dari baris terakhir
        last_row_features = X.iloc[-1].values  
        print(f"Last row features: {[f'{v:.6f}' for v in last_row_features]}")
        
        print(f"Feature columns dan nilai terakhir:")
        for i, col in enumerate(X.columns):
            print(f"  {col}: {last_row_features[i]:.6f}")
        
        # Prediksi
        prediction = predict_next_day(knn, scaler, last_row_features)
        predictions[name] = prediction
        
        print(f"Prediksi hari berikutnya: {prediction:.6f}")
    
    return predictions

# Jalankan prediksi yang sudah diperbaiki
print("PREDIKSI NO₂ HARI BERIKUTNYA")

corrected_predictions = predict_all_models()
